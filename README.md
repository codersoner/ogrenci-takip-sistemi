# Öğrenci Takip Sistemi

Python ve SQL Server kullanılarak geliştirilmiş bir öğrenci ders ve not takip sistemi.

## Özellikler

- Öğrenci ekleme
- Öğrencileri listeleme
- Öğrenci arama
- Öğrenci bilgilerini güncelleme
- Öğrenci silme
- Ders ve not ekleme
- Notları görüntüleme
- Ortalama hesaplama
- Harf notu hesaplama
- Geçti / kaldı durumu
- Ders silme
- Not güncelleme

## Kullanılan Teknolojiler

- Python
- SQL Server
- pyodbc
- Git
- GitHub
